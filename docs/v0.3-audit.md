# v0.3 — audit

## Doel

v0.3 maakt de controle- en reviewlaag zichtbaar als een bruikbaar operationeel dashboard, zonder nieuwe complexe datalogica toe te voegen.

## Toegevoegd

### Controle- en reviewdashboard
- Overzicht van alle Checks.
- Statusindicatoren:
  - 🟢 Goedgekeurd
  - 🟠 Review in behandeling
  - 🔴 Controle mislukt
  - 🔵 Controle uitgevoerd
  - 🔵 Controle bezig
  - ⚪ Nog niet gestart
- Totaaltellers per hoofdstatus.
- Overzicht van alle Reviews.
- Vanuit het dashboard kan een gebruiker naar de Check navigeren.
- Vanuit een Check/Review kan naar de concrete SourceVersion worden genavigeerd.

### Taakweergave
Taken tonen voortaan het aantal controles en de status van de meest recente controle.

### Reviewregel
Een afgeronde failed Check kan een Review krijgen, maar kan nooit worden goedgekeurd. Een failed Check kan alleen als rejected eindigen; voor een inhoudelijk correcte nieuwe beoordeling is een nieuwe SourceVersion en nieuwe Check nodig.

## Datamodel

Er is geen nieuwe persistente collectie toegevoegd. De bestaande keten blijft:

Project -> Task -> Source -> SourceVersion -> Check -> CheckResult -> Review

## Niet opgelost

ProtocolItems zijn nog niet versioned. Protocolinhoud mag daarom voorlopig niet inhoudelijk worden gewijzigd nadat er historische Checks mee zijn uitgevoerd.

## Besluit

v0.3 is een UI/statuslaag bovenop de bestaande v0.2-controleketen. De volgende ontwikkelstap kan pas worden bepaald nadat deze statusweergave in de praktijk is getest.
