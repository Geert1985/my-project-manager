# My Projects

Een mobiele, generieke project- en checklistwebapp.

## v0.1

- projecten aanmaken
- taken en subtaken aanmaken
- taken afvinken
- voortgang berekenen
- lokale opslag via localStorage
- responsive voor gsm en desktop

## Lokaal starten

Open `index.html` in een moderne browser.

Voor GitHub Pages kan de repository rechtstreeks als statische website gepubliceerd worden.

## Toekomst

De architectuur voorziet uitbreidingen voor bronnen, bronversies, controleprotocollen, reviews, notities, tags, zoeken en import/export.
